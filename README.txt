ACU MASTERS DIGITAL ID
=======================

HOW TO USE:
1. Upload the ZIP to Netlify Drop.
2. Netlify will give you a website link.
3. Your first profile will be:
   YOUR_NETLIFY_LINK/?id=bavly

IMPORTANT:
- The file index.html contains all HTML, CSS and JavaScript.
- Member data is near the bottom under "MEMBER DATA".
- Images are inside the images folder.

To add another member:
1. Put their image in the images folder.
2. Open index.html.
3. Copy the "bavly" member block.
4. Give the new member a unique ID.
5. Change name, department, university, community, role and image.
6. Upload the updated folder to Netlify.

Do NOT change the code below "DO NOT EDIT BELOW THIS LINE" unless you know JavaScript.
